# Urbano Nursery - Botanical Marketplace & Gardening Services

A botanical nursery e-commerce and gardening services web platform built with React, TypeScript, Tailwind CSS, and Vite.

## Features
- **Cinematic HD Botanical Background**: 1080p ambient botanical canopy video background with subtle atmospheric film.
- **Curated Plant Catalog**: Indoor and Outdoor plants filtered cleanly by category without redundant segregation.
- **Gardening Services & Booking**: Full service booking flow synced with the Gardener and Admin dashboards.
- **Artisan Tools & Plant Care**: Comprehensive collection of gardening tools and organic care essentials with unique imagery.
- **Portals & Dashboards**:
  - Customer Hub & Order Tracking
  - Nursery Partner Management
  - Gardener Schedule & Service Queue (receives user plant orders and booking requests)
  - Admin Operations & Inventory Control

## Local Development

```bash
# Install dependencies
npm install

# Start Vite development server
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

## Push to GitHub

### Option A: Using AI Studio UI
Click the **Export to GitHub** / **Push to GitHub** button in the top navigation of AI Studio. The repository is optimized (<36MB total) and imports smoothly.

### Option B: Using Git CLI
If you want to push to your own GitHub repository directly from the command line:

```bash
# 1. Add your GitHub repository remote (replace with your repo URL)
git remote add origin https://github.com/<YOUR_USERNAME>/<YOUR_REPOSITORY>.git

# 2. Rename branch to main if needed
git branch -M main

# 3. Push to GitHub
git push -u origin main
```
